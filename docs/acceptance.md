# 首版验收记录

## 已通过

- 后端 7 项自动检查：导入回滚、跨账户隔离、家长权限、CSRF、来源和 Host 校验、请求大小、提示判错、错词循环、幂等提交、调度升级和重置、停用账户会话撤销、词典失败、例句保存权限。
- 前端 TypeScript 检查和 Vite 生产构建。
- 前端导入解析、错误消息格式化断言检查。
- 浏览器：家长登录、JSON 导入、恢复学习、实体键盘 Enter 提交、提示词进入第二轮、第二轮正确后完成。
- 浏览器：鼠标点击页面键盘拼写 apple 并正确提交。
- 390px 视口：学习页 documentElement.scrollWidth 等于 innerWidth，无横向溢出。
- SQLite 在线备份后 PRAGMA integrity_check 返回 ok；正式库 WAL 模式和 schema version 1 已核对。
- 实际词典接口：应用使用的 httpx 可取得 hello 的英文解释、例句、音标和音频 URL。
- 同源生产静态入口返回 HTTP 200；正式数据库无测试账户。

## 尚未通过或需要实机

- 实际音频播放：独立 MP3 请求曾超时，不能以 URL 存在作为播放成功。
- 实际 TTS 听感：自动化浏览器有 speechSynthesis，但英语语音数量为 0。需安装语音包后在目标设备验证。
- 真实手机触摸、系统键盘、音频权限和 HTTPS 信任。
- 持续运行数日后的实际到期体验；当前调度由受控时间单元检查验证。
- 生成服务和云端 TTS：尚未接入，不保证任意词自动补齐完整内容。
