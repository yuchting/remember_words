# 首版验收记录

## 个人与整库备份更新

- 个人 JSON 不含账户名、密码、会话；覆盖仅当前用户，内部 ID 重映射，历史与阶段保留，原活动批次取消。自动备份和事务失败回滚有测试。
- 管理员整库 SQLite 导出清会话；恢复校验 schema、完整性、外键、可用家长与密码哈希资源边界，先备份再覆盖，失败回退有测试。
- 前端两种恢复均有严重警告、风险勾选、精确确认文字、重新输入密码及二次确认。真实浏览器验证入口和默认禁用状态；完整恢复结果由临时数据库 API 自动检查验证，未覆盖正式数据。
- 单 worker API gate 防止恢复与在途 API 交错；多进程访问同库不受支持。

## 已通过

- 后端 7 项自动检查：导入回滚、跨账户隔离、家长权限、CSRF、来源和 Host 校验、请求大小、提示判错、错词循环、幂等提交、调度升级和重置、停用账户会话撤销、词典失败、例句保存权限。
- 前端 TypeScript 检查和 Vite 生产构建。
- 前端导入解析、错误消息格式化断言检查。
- 浏览器：家长登录、JSON 导入、恢复学习、实体键盘 Enter 提交、提示词进入第二轮、第二轮正确后完成。
- 浏览器：鼠标点击页面键盘拼写 apple 并正确提交。
- 390px 视口：学习页 documentElement.scrollWidth 等于 innerWidth，无横向溢出。
- SQLite 在线备份后 PRAGMA integrity_check 返回 ok；正式库 WAL 模式和 schema version 1 已核对。
- 实际词典接口：应用使用的 httpx 可取得 hello 的英文解释、例句、音标和音频 URL。
- 同源生产静态入口返回 HTTP 200；正式数据库无测试账户。

## 尚未通过或需要实机

- 实际音频播放：独立 MP3 请求曾超时，不能以 URL 存在作为播放成功。
- 实际 TTS 听感：自动化浏览器有 speechSynthesis，但英语语音数量为 0。需安装语音包后在目标设备验证。
- 真实手机触摸、系统键盘、音频权限和 HTTPS 信任。
- 持续运行数日后的实际到期体验；当前调度由受控时间单元检查验证。
- 生成服务和云端 TTS：尚未接入，不保证任意词自动补齐完整内容。

## 数据与进程

- 自动检查使用临时数据库；浏览器检查使用系统批准的外部临时目录。

- 浏览器测试服务已停止，按 README 创建家长账户再启动。

## 导入与词库管理更新

- JSON 表格预览、重复词逐组选择、确认数量和真实后端导入已完成浏览器验证。
- XLSX 逐页解析和 Google 链接安全边界有自动检查；仅支持首行 word/words、meaning 的 XLSX。无效页单独报告原因；有效页支持多选合并预览，跨页重复统一处理。
- Google Sheets 导出所需 doc-…-sheets.googleusercontent.com 重定向已支持，伪造域名仍拒绝。用户提供的链接下载成功，但当次检查两个单词页均缺少 meaning 表头，说明页被跳过。
- 词库明细、改名、删除、JSON 导出、单词编辑、删除、记忆重置与历史接口有事务和账户隔离检查；真实后端浏览器已验证明细及历史展示。
- 私有 Google 文件采用已授权 gog，仅家长且 WORDS_GOG_PRIVATE=1；真实私有授权下载尚未联调。
- 修改释义、删除或重置会取消涉及该词的活动批次；例句编辑不影响判分，不取消批次。
- 记忆程度用复习阶段、答对次数和真实答题时间线表达，不虚构遗忘概率。
- 单进程登录限速，重启即清空；仅供局域网首版。
- 测试客户端有 Starlette 关于 httpx 的弃用提示，检查仍通过。
