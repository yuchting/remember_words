## 1. 已确认需求

- 第一版为局域网 Web 应用，电脑、手机浏览器均可访问。
- 后端使用 Python + SQLite；前端使用 Vue。
- 家长账户创建、管理孩子账户；孩子使用账户名、密码登录，不提供公开注册。
- 不同孩子的词库、学习记录、复习进度互相隔离。
- 上传或粘贴 JSON，创建独立逻辑词库，默认名称为学习开始时间。
- 按学校指定中文释义输入英文，严格拼写判分；不同词库可有同词，进度各自独立。
- 支持不规律、冲动式学习：一天多次、隔几天继续、考前速记，不限单次题量，随时保存恢复。
- 单库学习与跨多库综合复习共享逐词记忆；综合复习为一个固定队列任务，可跨 2～3 天续接，新增到期只提示重新发起。
- 支持实体键盘、系统键盘、页面软键盘（鼠标或触摸点击）。
- 首轮覆盖本次待学集合；后续练上一轮错词，独立答对但不流畅最多额外巩固一次，不能因 `hard` 无限循环。
- 当次过关后，按间隔复习规则安排后续复习。
- 必须具备完整英文例句、中文例句译文、单词发音、例句朗读；联网失败不阻断基本学习。
- 第二版可将前端通过 Capacitor 打包为 Android 应用；第一版不构建 Android 工程。

## 2. 范围与取舍

### 第一版包含

1. 家长初始化、登录、退出、孩子账户创建和密码重置。
2. JSON 导入、预览、错误定位、词库列表与详情。
3. 全量首轮、错词递归、暂停续学、答题记录。
4. 到期复习、分阶段间隔、基础进度统计。
5. 双输入方式、英文判分、提示和答案查看。
6. 例句、译文、单词音频、例句朗读、内容缓存与缺失状态。
7. 局域网部署、SQLite 备份和恢复说明。
8. 核心业务的可运行检查。

### 第一版不包含

- 公共注册、短信、邮件找回、社交登录。
- 排行榜、积分商城、语音识别、中文自由输入自动判分。
- 离线答题同步、多人实时协作、跨设备推送。
- 自适应遗忘模型训练、FSRS 接入。
- Android 打包、应用商店发布。
- 自动承诺达到永久记忆或全局最短学习时间。

## 3. 技术栈与部署形态

| 层 | 选择 | 原因 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite | 页面交互清晰，后续可复用为移动端 |
| 页面导航 | Vue Router | 登录、词库、学习、管理页面有明确路由 |
| 样式 | 原生 CSS，响应式布局 | 避免第一版引入完整 UI 框架 |
| 请求 | 浏览器 fetch | 无需额外请求库 |
| 后端 | FastAPI + Uvicorn | 请求校验、接口组织和部署直接 |
| 数据校验 | Pydantic | 复用 FastAPI 依赖 |
| 数据访问 | Python sqlite3 | 第一版无需 ORM |
| 密码哈希 | Argon2id，使用成熟库 | 不自行实现密码算法 |
| 发音兜底 | Web Speech API | 无需付费 Key；受设备语音包限制 |
| Android 后续 | Capacitor | 复用 Web 前端，后端继续运行在局域网主机 |

生产运行由 FastAPI 同源提供 `/api/*` 和 Vite 构建产物。开发阶段 Vite 代理 `/api`，不为开发便利放开任意来源 CORS。

SQLite 开启外键、WAL 和合理 busy_timeout；事务短小，不在数据库事务中调用外部接口。第一版单主机部署、单 Uvicorn worker，不引入 Redis、消息队列、容器编排。

依赖版本在开发启动时核对兼容性并锁定，不在计划中猜测未来版本号。

## 4. 页面设计

### 4.1 登录页

- 账户名、密码、明确的登录失败提示。
- 错误提示不区分账户不存在和密码错误。
- 支持浏览器密码管理器，不禁用粘贴。

### 4.2 家长管理页

- 创建孩子账户、重置孩子密码、停用和恢复账户。
- 查看孩子词库、学习摘要，为指定孩子导入词库。
- 家长管理行为通过专用受控接口执行，不使用孩子接口越权读取。
- 第一版不提供不可逆的账户删除，避免误删学习记录。

### 4.3 词库列表与导入页

- 展示名称、词数、首轮进度、到期数量、最近学习时间。
- 文件上传与 JSON 粘贴使用相同校验逻辑。
- 预览有效词、合并项、字段错误和内容缺失。
- 完成导入后提供“开始学习”和“稍后学习”。

### 4.4 学习页

- 中文释义、英文输入框、提交、不会、查看答案。
- 显示轮次、本轮剩余数量、已答对数量。
- 默认提交前不展示英文单词、例句或播放音频，避免泄露答案。
- 查看例句、提前播放发音或查看答案均视为提示，本题不能作为独立回忆成功。
- 答题后展示正确拼写、释义、完整例句和译文；提供单词发音、例句朗读。
- 可切换页面软键盘。布局支持手机竖屏和电脑横屏。
- 请求失败保留输入，提供重试；未确认保存前不跳下一题。

### 4.5 到期复习和结果页

- 默认先展示到期复习，再展示继续学习或新词库入口。
- 区分“当次过关”“当前复习阶段”“下次复习时间”。
- 统计首次正确率、错词数量、提示使用次数和学习耗时。
- 不用连续答对次数伪装为长期掌握率。

## 5. JSON 规范与导入规则

最小输入：

```json
[
  {"id": 1, "word": "hello", "meaning": "你好"},
  {"id": 2, "word": "world", "meaning": "世界"}
]
```

可选补充内容：

```json
[
  {
    "word": "hello",
    "meaning": "你好",
    "example": "She said hello to her new teacher.",
    "example_translation": "她向新老师问好。"
  }
]
```

校验约定：

- 顶层必须是非空数组；条目必须为对象。
- `word`、`meaning` 必须为非空字符串。
- 导入 `id` 不作为数据库主键，允许缺省或重复。
- 第一版限制：文件不超过 2 MiB，每库不超过 5000 条；单词不超过 100 字符，释义不超过 1000 字符，例句及译文各不超过 2000 字符。
- 字段先做 Unicode NFC 规范化、首尾空白清理；空白结果视为缺失。
- 精确重复的单词和释义合并；同词不同释义要求用户合并释义或明确保留为不同学习项。
- 第一版不接受导入音频 URL，避免引入任意地址抓取和音频授权问题。
- 不执行字符串表达式，不使用 eval，不猜测修复非法 JSON。
- 错误反馈包含数组位置、字段、原因；不返回内部异常堆栈。
- 全量校验成功后，事务创建词库和词条；失败整体回滚。

词库内部 ID 独立生成。默认名称在首次开始学习时生成，格式 `YYYY-MM-DD_HH-mm-ss`；尚未开始的词库使用导入时间临时名称。同名允许存在，界面显示创建时间区分。

## 6. 学习与调度规则

### 6.1 当次错词递归

1. 学习批次创建时冻结首轮词条集合，首轮覆盖全部未完成项。
2. 每轮开始生成并保存题目顺序，刷新页面不能重新抽题。
3. 提交由后端判分、记录结果，并推进游标。
4. 当前轮结束后，使用本轮错误、不会、使用提示的词生成下一轮；独立答对但 `hard` 的词最多加入一次额外流畅巩固。
5. 下一轮顺序持久化；没有错词或待完成的有限流畅巩固时结束当前批次。返回页面只暂停，不提前结束轮次。
6. 过关的词立即记录调度结果，不必等待整个词库结束；避免暂停后丢失有效学习成果。
7. 错词很少时仍只练错词与有限流畅巩固，显示可选短休息提示，不强制插入已会词。
8. 输入速度不直接判记忆强弱；有效输入至少三次删除／替换，或用户主动勾选吃力，提交 `effort='hard'`。粘贴、组合输入或窗口中断后不自动推断。该阈值是保守交互启发式，不是经过校准的记忆指标。

关键逻辑：

```python
# 设计示意：流畅巩固最多额外一次，实际字段以实现为准。
next_round = [item.word_id for item in round_results
              if not item.independent_correct or item.needs_one_fluency_practice]
complete = len(next_round) == 0
```

### 6.2 判分

```python
import unicodedata

def normalize_answer(value: str) -> str:
    return unicodedata.normalize("NFC", value).strip().casefold()

independent_correct = (
    normalize_answer(answer) == normalize_answer(expected)
    and not hint_used
)
```

- 忽略首尾空白和英文大小写。
- 不容忍少字母、多字母、内部空格、连字符或撇号差异。
- 英美拼写变体第一版不自动扩展；需要时后续增加显式可接受答案字段。
- 空输入提交提示输入内容；点击“不会”明确记录失败。
- 正确答案来自数据库，不信任客户端提交的正确性或提示状态。
- 获取揭示内容的接口在后端记录提示，不能只靠前端布尔值。

### 6.3 跨时段调度（实施目标，待验收）

本次采用基于实际间隔的保守启发式，非概率模型；FSRS 未来评估，不宣称已科学校准。

- 首次独立答对：600 秒后建议再练。
- 距上次接触达到既有记忆间隔时独立答对：新间隔为实际间隔的 2 倍，上限 30 天。
- 未达到既有间隔的近期答对：保留原记忆间隔和到期时间，不靠短时刷题连续升级。
- 失败：间隔缩为原来的 1/4，限制在 600 秒～1 天；未过关新词仍保持未学。
- `hard`：缩为 600 秒；提示、答案曝光及重输更新接触时间，但不提供成功回忆证据。
- `stage` 由间隔映射，仅兼容历史展示；不再是调度算法核心。旧阶段只用于初始化既有间隔，不补造历史间隔检验数据。

- 使用真实经过时间，而非轮次数或页面停留时间；支持同日多次、跨日及逾期学习。
- 每次提交保存逐词调度，不等整轮结束；立即曝光后的重输不算长期回忆，不能靠短时循环连续升级。
- `hard` 仅辅助描述输入流畅度，不改变 `correct`；独立答对但不流畅最多额外巩固一次，避免无限循环。
- 单库学习与综合复习共享词条记忆状态；跨库同词仍为独立词条。
- 综合复习发起时冻结多库到期集合，可显式包含未学／尚未过关词，只建一个任务；跨 2～3 天恢复仍使用原队列，错词进入后续轮次。
- 任务外新增到期仅提示重新发起；活动任务涉及词库不得建立重叠任务，逾期不生成欠账副本。
- 返回、刷新或关闭只暂停，不结算、不撤销；未答不计错。存储 UTC，展示本地时区。

设计关键符号（职责目标，不代表全部已验收）：

| 符号 | 职责 |
|---|---|
| `start_study` | 创建或恢复单库／多库固定队列，校验归属及重叠任务，不静默追加到期词 |
| `submit` | 严格判分，幂等保存答题及逐词调度，区分独立回忆、曝光重输与 `hard` |
| `schedule` | 接收可注入的真实时间，保守更新逐词复习时间，不输出记忆概率 |
| `finish_round` | 生成报告及后续错词／有限流畅巩固队列，不集中重排已提交词的调度 |

目标检查：可控时间覆盖即时重输、同日多次、跨天恢复、逾期和幂等；浏览器、目标设备及长期效果另行验证。

## 7. 完整例句与发音方案

### 7.1 必须区分的能力

- 单词中文释义：导入 JSON 为准。
- 完整英文例句及中文译文：每词至少一组，可来自用户导入或联网补全。
- 单词发音：优先词典音频；无音频时尝试设备英语 TTS。
- 例句朗读：默认设备英语 TTS；设备不可用时明确提示，不假装已具备朗读能力。

Free Dictionary API 只作为免费词典首选来源，不能保证每个词都有例句、中文翻译或音频，因此不能作为“完整内容”的唯一保障。

### 7.2 内容来源顺序

1. 用户导入的例句、译文优先，不自动覆盖。
2. 查询 Free Dictionary API，补全解释、音标、可用例句与单词音频。
3. 若例句或译文仍缺失，可使用家长配置的一个文本生成服务补全。具体供应商和模型待开发前确认，不承诺永久免费或固定免费额度。
4. 未配置服务、请求失败或结果校验失败时，显示缺失原因，支持家长手工补全。

关键边界：仅靠任意免费接口无法保证任意输入单词内容完整。基础学习允许继续；只有例句、译文和可用播放方式均具备时，才显示“内容就绪”。验收必须覆盖免费来源缺失、补全失败、设备无英语语音包等情况。

### 7.3 生成与安全

- 生成服务仅接收单词、中文释义和固定任务要求，不发送孩子姓名、账户或答题历史。
- 输出限定 JSON：`example`、`example_translation`；校验类型、长度、空值，禁止直接作为 HTML 渲染。
- 生成内容标记来源及“自动生成，需核对”；不把结构校验等同于语义正确。
- 不建设多供应商插件体系，只接入最终选定的一家服务。
- Key 仅保存在服务端环境变量，家长界面最多展示是否配置，不回传密钥。
- 外部请求设置超时和响应体上限；失败由用户重试，不无限后台重试。
- 词典缓存按规范化单词保存；生成例句按单词和中文释义缓存，避免多义词释义混用。
- 记录来源、获取时间、内容状态；音频授权与缓存条件实施前核实。
- 不提供任意 URL 代理。音频如需后端中转，只允许核实的 HTTPS 来源；逐跳校验重定向并禁止私网、回环、链路本地目标。

### 7.4 播放交互

- 单词和例句分别提供播放按钮。
- 用户点击后播放，不依赖浏览器自动播放。
- 播放前停止上一段，防止重叠。
- 可配置朗读速度，默认正常速度。
- 单词音频失败时尝试 TTS；两者不可用时给出设备设置提示。
- 局域网浏览器和 Android WebView 的英语语音可用性需分别实机验证。

## 8. 数据模型

| 表 | 关键字段与职责 |
|---|---|
| users | id、username、password_hash、role、is_active、created_at |
| auth_sessions | token_hash、user_id、expires_at；登出和改密可撤销 |
| decks | id、user_id、name、created_at、started_at |
| words | id、deck_id、word、meaning、example、example_translation、内容来源 |
| review_states | word_id 唯一、stage、due_at、updated_at |
| study_sessions | id、user_id、deck_id 可空、kind、status、round_number、created_at |
| study_items | 批次、轮次、词条、顺序、是否揭示提示、提交状态 |
| attempts | study_item_id 唯一、answer、independent_correct、duration_ms、created_at |
| dictionary_cache | 缓存键、结果、来源、状态、获取与过期时间 |

`study_items` 持久化固定队列，不能仅在内存保存。单库任务可独立恢复；综合复习一个任务可涉及多个词库，涉及词库不得建立重叠任务。多标签页提交相同题目时只接受一次。

关键索引和约束：

- `users.username` 唯一，账户名规范化规则前后端一致。
- `auth_sessions.token_hash` 唯一。
- `review_states.word_id` 唯一；建立 `due_at` 查询索引。
- `study_items(session_id, round_number, position)` 唯一。
- `attempts.study_item_id` 唯一，提供天然幂等提交。
- 所有外键启用；账户停用不删除历史。
- 通过 decks 和 study_sessions 的用户归属校验访问；SQL 始终使用参数绑定。

数据库 schema 版本使用 `PRAGMA user_version`；第一版仅维护当前版本，首次发生结构升级时再增加最小升级脚本。

| POST | /api/admin/users | 家长创建孩子账户 |
| PATCH | /api/admin/users/{id} | 停用、恢复、重置密码 |
| GET | /api/admin/users/{id}/summary | 家长查看孩子摘要 |
| POST | /api/admin/users/{id}/decks/import | 家长为指定孩子导入 |
| POST | /api/decks/import | 当前账户导入 |
| GET | /api/decks | 自己的词库 |
| GET | /api/decks/{id} | 词库详情与进度 |
| POST | /api/decks/{id}/study | 创建或恢复学习批次 |
| POST | /api/reviews/study | 创建到期复习批次 |
| GET | /api/reviews/due | 到期数量和摘要 |
| GET | /api/study/{id}/next | 当前题，不返回未揭示答案 |
| POST | /api/study/{id}/items/{item_id}/reveal | 记录提示并揭示内容 |
| POST | /api/study/{id}/items/{item_id}/answer | 判分、持久化、推进 |
| GET | /api/study/{id}/summary | 批次结果 |
| POST | /api/words/{id}/enrich | 补全授权词条的内容 |

当前题使用不包含拼写的响应模型；内容和词典缓存接口不能成为绕过题目揭示限制的路径。应用用于学习，不承诺防止孩子通过开发者工具或外部词典作弊。

答题事务顺序：校验会话和题目归属，检查已提交状态，后端判分，写入 attempts，更新题目与复习状态，必要时创建下一轮或结束批次，统一提交。相同题目的重复请求返回既有结果，不再次推进。

## 10. 账户和局域网安全

- 首个家长账户通过主机命令行初始化，不开放无保护的首次注册页面。
- 家长角色不可由客户端任意设置；孩子不能调用管理接口。
- Argon2id 存储密码哈希；密码长度设上下限，不使用默认密码。
- 登录使用随机高熵会话令牌，服务端只保存令牌哈希。
- Cookie 使用 HttpOnly、SameSite=Lax、明确有效期；修改请求校验 CSRF Token 和来源。
- 登录失败限速，改密和停用撤销现有会话。
- 局域网推荐 HTTPS。若开发阶段临时使用 HTTP，必须明确浏览器到主机的密码与会话未加密，不能宣称安全；HTTP 下不能设置仅 HTTPS 可用的 Secure Cookie。
- 正式 HTTPS 模式启用 Secure Cookie；不把关闭安全校验作为部署步骤。
- 配置受信任 Host，不对所有来源开放 CORS。
- 只向可信局域网开放端口，不做公网端口映射。
- 数据库和密钥文件不在静态目录；日志不记录密码、Key、Cookie 或完整会话令牌。

## 12. 分阶段开发与验收

### 阶段 0：内容来源与运行环境验证

工作：

- 确认开发主机 Python、Node 环境和局域网访问方式。
- 核对依赖、Web Speech API、词典响应及音频来源。
- 使用常见词、短语、多义词、缺失词验证例句、译文、发音链路。
- 确认是否配置生成服务，以及设备无 TTS 时是否需要云端语音服务。

交付：内容可用性结论、最终供应商选择、环境配置项。

验收：不把词典偶尔返回例句视为全面覆盖；不能提供的能力明确标为缺失。

### 阶段 1：账户与数据基础

工作：数据库初始化、家长命令行创建、登录退出、孩子管理、会话与权限。

验收：

- 家长可创建孩子 A、B；孩子不可创建管理账户。
- A 使用 B 的资源 ID 访问时被拒绝。
- 停用或重置密码后旧会话失效。
- 数据库无明文密码、明文会话令牌。

### 阶段 2：JSON 导入与词库

工作：上传和粘贴、同一套校验、导入预览、事务入库、开始时间命名。

验收：

- 最小 JSON 可导入；重复输入 ID 不冲突。
- 超限、无效类型、缺字段、非法 JSON 返回可定位错误。
- 同词异义必须明确处理，不悄悄覆盖。
- 失败不留下半个词库；孩子间数据隔离。

### 阶段 3：当次学习闭环

工作：判分、队列、提示、软键盘、错词递归、暂停恢复、幂等提交。

验收：

- 首轮全量；第二轮仅首轮错词；后续递推。
- 提示词进入下一轮，不能按独立答对处理。
- 刷新、断网重试、多标签重复提交不丢进度、不重复推进。
- 手机触摸、电脑键盘和鼠标均可完成学习。

### 阶段 4：跨天复习

工作：阶段调度、到期查询、维护间隔、批次互斥、学习摘要。

验收：

- 用可控时间验证真实间隔、同日多次、跨日及逾期，不把曝光重输当长期回忆。
- 逐次提交保存调度；返回只暂停，不结算、不丢队列。
- `hard` 不改 `correct`，额外流畅巩固最多一次；错词循环不能连续升级。
- 多库综合复习只建一个固定任务，跨 2～3 天续接；新增到期仅提示重新发起，活动任务不重叠。

### 阶段 5：例句、发音与失败兜底

工作：词典查询、例句和译文补全、缓存、音频和 TTS、来源标记、手工补全入口。

验收：

- 有词典例句、无例句、无音频、查无此词均有明确行为。
- 词条可展示完整英文句子及对应中文译文。
- 单词、例句可分别播放；不可用时有明确提示和修复路径。
- 提交前请求提示会被后端记录。
- 外部接口超时不影响继续答题；Key 不出现在浏览器请求、源码或日志中。

### 阶段 6：局域网交付

工作：前端构建、同源服务、主机监听地址、防火墙、HTTPS、备份恢复说明。

验收：

- 同一局域网的电脑和手机可登录学习。
- 服务器重启后账户、轮次和计划保留。
- 从备份恢复到新数据库后可继续原学习批次。
- 外网无法通过路由器端口映射访问。
- 文档列出启动、停止、备份、恢复、密钥配置和 TTS 排查步骤。

阶段按验收完成推进，不以页面存在替代业务规则通过。

## 14. 备份与恢复

- 使用 sqlite3.Connection.backup，不在 WAL 写入期间直接复制单个数据库文件。
- 第一版提供主机命令备份，不建设后台备份管理页面。
- 备份放在不公开的目录，文件名带 UTC 时间；保留策略由家长指定。
- 恢复前停止服务，保留当前数据库的安全副本；确认后替换并检查数据完整性。
- API Key 不放入数据库备份；单独安全保管环境配置。
- 发布前完成一次实际恢复演练。
