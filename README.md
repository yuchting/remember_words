# 单词记忆

面向家长与孩子的局域网 Web 应用。Vue 3 + TypeScript + FastAPI + SQLite；按学校指定中文释义输入英文，严格校验拼写（仅忽略大小写、首尾空白及 NFC 差异）。支持不规律学习：一天多次、隔几天继续或考前速记，不限制每次题量，随时暂停恢复。学习与调度规则、验证范围见 [验收记录](docs/acceptance.md)。

## 功能

- 家长创建和管理孩子账户，词库、答题历史、复习进度互相隔离。
- JSON、XLSX、Google Sheets / Drive 导入：先预览，处理重复词，再确认入库。
- 表格扫描全部工作表：有效页可多选，显示词数及前 5 个单词；无效页提示原因。选中页合并为一个词库，跨页统一去重。
- 单库首轮覆盖未学及当前到期词，后续练错词、至多一次的额外流畅巩固及范围内 FSRS 到期词；支持暂停续学、实体键盘与页面软键盘。页面软键盘默认收起，点击“展开软键盘”显示；不控制设备系统输入法。
- 使用 FSRS 按真实间隔与回忆表现逐词排期，单库学习与综合复习共用状态；以前答对的词也会在到期后重新入选。默认目标保持率 90% 不是个人成绩或效果保证，参数尚未按个人历史训练。即时重输不算长期回忆，考前集中练习不等于长期掌握。
- 词库改名、明细、删除、JSON 导出；单词释义与例句编辑、删除、记忆重置、真实答题趋势。
- 免费词典解释与单词音频；可由家长配置 Azure / Google 云端朗读单词和例句，支持主备用。云端关闭时保留词典／设备 TTS；云端开启时设备回退默认关闭。揭示或提交答案后自动朗读，浏览器可能限制自动播放，可点击“朗读单词”重播。免费词典可能缺失例句和译文，可导入或手工补齐。
- 提交后“继续”倒计时：快速独立答对 1 秒、普通正确（含巩固拼写正确）2 秒、错误或不会 3 秒。快速要求题目显示到首次输入、相邻输入、最后输入到提交均严格小于 1000ms，且无删除、替换、粘贴、揭示答案；实体键盘和页面软键盘均支持。倒计时期间点击和回车均不能继续，结束后需重新操作；长按回车不会连续跳题。
- 错误或不会后显示答案并自动朗读；继续时仍是同一个词，清空输入、隐藏答案，直到拼写正确。巩固只完成重输，不覆盖首次错误、不计独立回忆、不升级，也不移除下一轮错词。揭示后拼写匹配可结束巩固，但仍不算独立答对。刷新或重新登录保留巩固状态；巩固未完成也可返回词库，首次错误记录仍保留。末题错误先巩固，再显示原轮次报告。冷却及快速输入判定仅为前端交互，不作为防作弊边界。

## Linux 系统服务与反向代理

运行 `sudo ./sop.sh service` 原地安装或更新 systemd 服务，支持开机启动、故障重启；数据库位于本项目 `data/words.sqlite3`，已被 Git 忽略。脚本不安装或修改 Nginx。`./sop.sh start|stop|status|restart` 自动检测已安装服务并交由 `systemctl` 管理，未安装时使用原后台模式。HTTPS 子路径首次安装可用 `sudo WORDS_BASE_PATH=/words WORDS_HTTPS=1 ./sop.sh service`；代理由用户手动配置。步骤见[部署文档](docs/deployment.md#systemd-本地服务)。

提供“单库学习”和“跨多库综合复习”两个入口，共享同一词条的记忆状态；不同词库中的相同单词各自保存进度。涉及同一词库的活动任务不得重叠。综合复习多选词库后创建一个固定队列任务，默认纳入发起时已过关且到期的词，可勾选包含未学／尚未过关词；可跨 2～3 天暂停恢复，错词进入后续轮次。任务外新增到期词仅提示重新发起，不静默加入当前队列。

学习进度按轮次、题目自动保存。首页“继续学习”显示当前轮次、已完成/总词数及剩余数量，刷新或重新登录后仍可继续。首轮覆盖本次待学词，之后每轮包含上一轮未独立答对的词、有限吃力巩固及任务范围内按 FSRS 到期的词；以前答对的词也可能重新出现。单库可重新筛选该词库，综合复习仅在本次固定词条集合内滚动；集合外新增到期另行提示。连续不会的词继续入选，直到独立答对。输入流畅度 `hard` 来自主动勾选“回忆吃力”或有效输入中的至少三次删除／替换；粘贴、组合输入或窗口中断后不自动判吃力。输入速度本身不决定记忆强弱。`hard` 仅作辅助，不改变拼写判分 `correct`；独立答对但不流畅的词最多额外巩固一次，不因 `hard` 无限循环。未提交输入不保存，已提交题目不重复推进。每次提交立即保存答题与逐词调度；无需等整轮结束排期。“返回词库”、关闭页面或刷新只暂停，不结算、不撤销、不把未答词算错，恢复时继续原队列。保存失败显示错误，未确认保存前不推进。每轮自然结束显示逐词结果报告；下一轮入选情况不是科学记忆概率，不提供撤销本轮记录的按钮。

导航“总体统计”汇总当前账户全部词库，可筛选单个词库及近 7 天、30 天或全部历史；提供各库过关比例 bar、阶段分布、跨库高频错词、词库学习/综合复习首轮独立正确率、间隔回忆表现、每日作答与答对趋势、未来 7 天到期分布。当前库存及阶段不受历史时间筛选影响。历史按 UTC 自然日聚合；不同词库中的相同单词按独立词条计数。提示、不会和答错均计入未独立答对；巩固重输不重复计数。间隔回忆仅统计新记录中距上次接触至少 10 分钟且未揭示答案的检验，即时重输不计入；这不是长期掌握率。旧记录缺少间隔信息，不推算。现有记录无法可靠还原每日新增过关数量，不推算该指标。

每个词库卡片的“统计信息”可查看已过关百分比、全部/已过关/尚未过关/到期待复习数量、阶段分布和尚未过关的词。已过关按当前阶段 0–5 统计，每次提交即时更新，不表示永久掌握或精确记忆概率；阶段 -1 为尚未过关。

## 启动

环境：macOS / Linux、Bash、Python 3.11+、Node.js 22.12+、npm。

```sh
./sop.sh start
./sop.sh status  # 显示状态，不进入分页器
./sop.sh restart
./sop.sh stop
./sop.sh admin   # 重置管理员密码；没有管理员时输入用户名创建
```

首次启动自动创建虚拟环境、安装锁定依赖、构建前端，并引导创建家长账户。之后登录网页创建孩子账户。

忘记管理员（家长）密码时，在服务器终端运行 `./sop.sh admin`：一个管理员直接确认，多个管理员按序号选择；没有管理员时输入用户名创建。密码隐藏输入并确认两次，长度 8–128 字符。重置后该管理员原登录会话失效，学习数据不变；停用账户不会自动启用。命令需要已安装的 `.venv` 和 Python 依赖，不构建前端、不重启服务。自定义数据库必须显式指定 `WORDS_DB=/实际路径/words.sqlite3 ./sop.sh admin`，与运行服务保持一致；不会读取 `.env` 或 systemd 环境配置。仅允许可信服务器操作者运行此命令。

- 本机访问：**http://127.0.0.1:18765**。
- 其他设备：使用 `http://服务器局域网IP:18765`，不要将 `0.0.0.0` 当作访问地址。
- 默认监听所有 IPv4 网卡 `0.0.0.0:18765`；自动探测本机 IP 配置 Host 校验。
- 日志：`.run/server.log`；默认数据库：`data/words.sqlite3`。
- 启动、重启按内容哈希检查构建：前端源码、配置、依赖锁、后端 Python 或有效路径变化，或 `dist` 缺失/被手动覆盖时，重新构建；未变则跳过。依赖锁变化自动补齐依赖。systemd 模式从实际服务环境文件只读解析 `WORDS_BASE_PATH`，不会执行配置。构建失败保留旧服务与旧产物；不停止占用端口的其他程序。

**HTTP 不加密密码和会话，仅在可信局域网临时使用。不要配置公网端口转发；正式使用推荐 HTTPS。**

### Android Chrome 安装为应用

提供 Web App Manifest 和应用图标，使用 `standalone` 独立窗口模式：从桌面应用图标启动时隐藏 Chrome 地址栏和菜单栏，保留安卓状态栏。根路径和 `/words/` 等部署子路径均支持。

1. 使用手机信任证书的 **HTTPS 地址**打开网页；普通 `http://局域网IP:18765` 不满足安装条件，可能只能创建仍带浏览器界面的快捷方式。
2. Chrome 菜单选择“添加到主屏幕 → 安装”（不同版本可能显示“安装应用”）。
3. 从新增的桌面应用图标打开，而不是从 Chrome 标签页进入。若原来添加过普通快捷方式，删除旧快捷方式后重新安装。

不提供离线缓存，服务器仍需运行且手机需能访问服务器。浏览器可能拒绝不可信证书；不要通过忽略证书警告替代可信 HTTPS 配置。HTTPS 配置见[部署文档](docs/deployment.md)。Android Chrome 实机安装与独立窗口显示仍需目标设备验收。

### 自定义配置

```sh
HOST=0.0.0.0 PORT=18765 \
WORDS_HOSTS=localhost,127.0.0.1,192.168.1.100 \
./sop.sh restart
```

| 变量 | 用途 |
|---|---|
| `HOST` / `PORT` | 脚本监听地址、端口；仅本机使用可设 `HOST=127.0.0.1` |
| `WORDS_HOSTS` | 允许访问的服务器 IP / 域名，逗号分隔；不是客户端 IP 名单 |
| `WORDS_DB` | 自定义 SQLite 路径 |
| `PYTHON` | 创建虚拟环境时使用的 Python 命令 |
| `WORDS_HTTPS` | `1` 启用 Secure Cookie；脚本还需 `TLS_CERT`、`TLS_KEY` 才开启 TLS |
| `WORDS_GOG_PRIVATE` | `1` 允许家长通过已授权的 `gog` 回退读取私有 Google 文件 |

脚本不自动加载 `.env`，也不保存自定义环境变量；重启时需再次传入。TLS、手动启动、备份恢复见[部署文档](docs/deployment.md)。

## 导入格式

```json
[
  {"word": "hello", "meaning": "你好"},
  {"word": "world", "meaning": "世界"}
]
```

- JSON 必填 `word`、`meaning`，可选 `example`、`example_translation`；导入 `id` 不作为数据库主键。
- XLSX 第一行必须有 `word`（兼容 `words`）、`meaning`，可带上述例句列；不支持 `.xls`，不猜测纠正拼错的表头。
- 重复检查限本次导入，忽略单词大小写、首尾空白；用户选择保留一条或整组排除。不同词库可有同词。
- 请求和文件不超过 2 MiB，每库最多 5000 个词。词库默认以导入时间命名，可修改。
- Google 链接先公开下载；无法公开访问时才尝试家长授权的 `gog`。格式错误不回退私有读取。服务器需预先安装并授权 `gog`，私有下载尚需真实授权联调。
- 删除会移除相应历史；重置词条保留内容、清除该词答题历史与进度。修改释义、删除、重置会结束涉及该词的活动批次，操作前有确认。

## 个人备份

每个用户可在“个人备份”导出自己的全部词库、词条、答题历史和复习进度。**文件不包含账户名、密码或登录会话**，不能当作管理员整库备份使用。

个人导入不是合并：只覆盖当前登录用户的学习数据，不修改账户名、密码，不影响其他用户；恢复的学习批次不自动继续。要求当前密码、勾选风险、输入“确认覆盖我的学习数据”和二次确认。覆盖前自动保存当前个人数据备份，文件和请求不超过 2 MiB。

## 整库备份与覆盖恢复

家长管理页提供整库导出与恢复，两者都要求重新输入当前家长密码。导出包含全部账户（含密码哈希）、词库、学习历史与复习计划，不包含登录会话、服务器密钥或 Google 授权。备份属于敏感文件，请勿公开分享。

**恢复不是合并：当前所有账户、词库和学习记录将被备份内容整体替换，所有用户退出登录。恢复后必须使用备份中的家长账户和密码。** 用户必须勾选风险确认、输入“确认覆盖整个数据库”、重新输入当前密码并再次确认。上传限 50 MiB，仅接受当前版本的有效数据库；先校验，再自动备份当前库到数据库目录的 `backups/`，最后覆盖。操作失败应检查提示，不盲目重复提交。

当前仅支持单 worker。恢复时暂停其他 API 请求，避免在途答题写入已覆盖的数据。需要回退时，从主机保管的自动备份恢复，步骤见部署文档。

## 云端朗读：Azure + Google 配置教程

仅家长／admin 可打开“云端朗读”。设置家庭共用，孩子不能查看或修改密钥。云端会收到单词或英文例句，可能产生费用；请先确认服务商价格、数据处理条款和预算。本站不提供字符统计或月额度管理。

### 1. 准备 Azure AI Speech

1. 登录 [Azure Portal](https://portal.azure.com/)，创建 Azure AI Speech（Speech service）资源。订阅、资源组、区域和定价层按账户实际选择；免费层是否可用以控制台为准。
2. 打开资源的“Keys and Endpoint／密钥和终结点”，复制一个 key，并记下资源区域代码，例如 `eastus`。必须填写该资源真实区域，不是浏览器所在地区，也不是完整 endpoint URL。
3. 在本站“云端朗读”填写 Azure Region、Voice 和新 API key。默认英语音色 `en-US-JennyNeural`；其他音色必须使用官方完整名称。
4. 参考 [创建 Speech 资源与密钥](https://learn.microsoft.com/azure/ai-services/speech-service/get-started-text-to-speech)、[语言和音色列表](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts)、[Speech 定价](https://azure.microsoft.com/pricing/details/cognitive-services/speech-services/)。

### 2. 准备 Google Cloud Text-to-Speech

1. 登录 [Google Cloud Console](https://console.cloud.google.com/)，创建或选择项目，按控制台要求启用结算。
2. 在 API 库启用 [Cloud Text-to-Speech API](https://console.cloud.google.com/apis/library/texttospeech.googleapis.com)。
3. 在“API 和服务 → 凭据”创建 API key，将 API 限制设为 Cloud Text-to-Speech API。请求从服务器发出，不要使用浏览器 HTTP referrer 限制；有固定出口 IP 时可按服务器出口限制。不要将服务账号 JSON 内容填入 API key。
4. 在本站填写新 Google API key 和完整 Voice 名称，默认 `en-US-Neural2-F`。Google 不需要 Azure Region。
5. 参考 [API key 管理](https://cloud.google.com/docs/authentication/api-keys)、[Text-to-Speech 入门](https://cloud.google.com/text-to-speech/docs/before-you-begin)、[支持的音色](https://cloud.google.com/text-to-speech/docs/voices)、[价格](https://cloud.google.com/text-to-speech/pricing)。

已保存的 API Key 输入框显示 `*****` 占位符，旁边标注“已设置”；不回显真实密钥。留空保存保留原密钥，输入新密钥才替换。

每家服务配置旁提供“查看额度／账单（新窗口）”，分别打开 Azure、Google Cloud 官方计费页面。需自行登录并选择对应订阅／结算账号；本站不读取余额，也不会向链接传递 API Key。免费层、剩余赠金和实际费用以官方控制台为准。

### 3. 保存、试听、回退

1. 选择主服务，如 Azure；备用选 Google，或“不使用备用”。主服务选“关闭云端朗读”时，继续使用原有词典音频／设备英语语音。
2. 可选“云端失败后允许设备英语语音回退”，默认不勾选。开启云端但不允许设备回退时，失败显示错误，不静默使用设备语音。
3. 每家 API key 旁有“测试一下”：直接使用当前填写的密钥、音色及 Azure Region；密钥留空时用该服务已保存密钥。测试不保存设置、不使用备用服务或缓存，可能产生少量费用。播放开始会显示提示，是否真正听到声音需人工确认。确认后点击“保存设置”；“试听已保存配置”用于检查已保存的主备链路。单词和例句使用已保存音色，云端语速固定 `0.9`，没有语速设置。
4. 密钥只显示“已设置／未设置”，不会回显。新 key 留空保留旧值；勾选“保存时清除”则删除对应 key。修改密钥后保存会清空输入框。
5. 学习页点击“朗读单词／朗读例句”验证。浏览器可能拦截自动播放；首次操作请手动点击，设备回退需要可用英语语音包。

遇到失败：先查 key、Azure 区域、完整 Voice 名、Google API 启用／结算、服务器网络和服务商额度。`429` 可能来自本站每账户每分钟 30 次限制或上游限流；暂停后再试。`502` 检查服务商配置／网络，禁止把 key 粘贴到日志或问题报告。

### 4. 缓存与备份

后台显示缓存文件数、已用容量和上限，可刷新；“清空缓存”需要确认，不删除学习记录或设置，但下次合成可能收费。单词和例句按文本、服务、音色去重；请求优先检查已配置主／备用服务的缓存，避免主服务失败时反复联网。缓存上限 `100 MiB`，超限按最旧生成顺序清理（FIFO），不是最近访问顺序。

配置和密钥保存在数据库目录的独立 `speech/settings.json`，文件权限 `600`，重启保留。配置、密钥和音频缓存不包含在个人或整库备份中。备份迁移后须单独安全配置云端朗读；主机管理员应限制该目录访问。详细运维见 [部署文档](docs/deployment.md)。
