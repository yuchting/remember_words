# 单词记忆

面向家长与孩子的局域网 Web 应用。Vue 3 + TypeScript + FastAPI + SQLite；中文提示，输入英文。

## 功能

- 家长创建和管理孩子账户，词库、答题历史、复习进度互相隔离。
- JSON、XLSX、Google Sheets / Drive 导入：先预览，处理重复词，再确认入库。
- 表格扫描全部工作表：有效页可多选，显示词数及前 5 个单词；无效页提示原因。选中页合并为一个词库，跨页统一去重。
- 首轮覆盖未学词，后续只练错词；支持暂停续学、实体键盘与页面软键盘。
- 当次过关后按 10 分钟、1/3/7/14/30 天复习；失败重学，最后保持 30 天维护间隔。
- 词库改名、明细、删除、JSON 导出；单词释义与例句编辑、删除、记忆重置、真实答题趋势。
- 免费词典解释与单词音频、设备 TTS 朗读例句。揭示或提交答案后自动朗读单词，网络音频不可用时回退设备英语 TTS；浏览器可能限制自动播放，可点击“朗读单词”重播。免费来源可能缺失，例句和译文可导入或手工补齐。
- 提交后“继续”倒计时：快速独立答对 1 秒、普通正确（含巩固拼写正确）2 秒、错误或不会 3 秒。快速要求题目显示到首次输入、相邻输入、最后输入到提交均严格小于 1000ms，且无删除、替换、粘贴、揭示答案；实体键盘和页面软键盘均支持。倒计时期间点击和回车均不能继续，结束后需重新操作；长按回车不会连续跳题。
- 错误或不会后显示答案并自动朗读；继续时仍是同一个词，清空输入、隐藏答案，直到拼写正确。巩固只完成重输，不覆盖首次错误、不计独立回忆、不升级，也不移除下一轮错词。揭示后拼写匹配可结束巩固，但仍不算独立答对。刷新或重新登录保留巩固状态；巩固未完成不能中断或提前完结本轮。末题错误先巩固，再显示原轮次报告。冷却及快速输入判定仅为前端交互，不作为防作弊边界。

## Linux 系统服务与反向代理

运行 `sudo ./sop.sh service` 原地安装或更新 systemd 服务，支持开机启动、故障重启；数据库位于本项目 `data/words.sqlite3`，已被 Git 忽略。脚本不安装或修改 Nginx。`./sop.sh start|stop|status|restart` 自动检测已安装服务并交由 `systemctl` 管理，未安装时使用原后台模式。HTTPS 子路径首次安装可用 `sudo WORDS_BASE_PATH=/words WORDS_HTTPS=1 ./sop.sh service`；代理由用户手动配置。步骤见[部署文档](docs/deployment.md#systemd-本地服务)。

学习进度按轮次、题目自动保存。首页“继续学习”显示当前轮次、已完成/总词数及剩余数量，刷新或重新登录后仍可继续。首轮覆盖本次待学词，之后每轮只练上一轮未独立答对的词；连续不会的词会反复入选，直到独立答对。未提交的输入不保存；已提交的题目不重复推进。答题记录先保存，轮次自然完成或提前完结时才结算记忆阶段和复习时间。每轮自然结束或提前完结后，用表格列出单词、释义、逐词评价、下一轮入选率及记忆阶段，按错词、未答、独立答对排序，不显示答题时间；下一轮入选率为独立答对 0%、错误或未答 100%，不是科学记忆概率。“中断本轮”会撤销本轮全部答题与提示记录，不计成绩，下次从本轮开头重来；普通返回词库仍保留进度。“提前完结”只结算已答词，未答不计分，错误及未答词进入下一轮。

每个词库卡片的“统计信息”可查看已过关百分比、全部/已过关/尚未过关/到期待复习数量、阶段分布和尚未过关的词。已过关按已结算阶段 0–5 统计，不表示永久掌握或精确记忆概率；阶段 -1 为尚未过关。

## 启动

环境：macOS / Linux、Bash、Python 3.11+、Node.js 22.12+、npm。

```sh
./sop.sh start
./sop.sh status  # 显示状态，不进入分页器
./sop.sh restart
./sop.sh stop
./sop.sh admin   # 重置管理员密码；没有管理员时输入用户名创建
```

首次启动自动创建虚拟环境、安装锁定依赖、构建前端，并引导创建家长账户。之后登录网页创建孩子账户。

忘记管理员（家长）密码时，在服务器终端运行 `./sop.sh admin`：一个管理员直接确认，多个管理员按序号选择；没有管理员时输入用户名创建。密码隐藏输入并确认两次，长度 8–128 字符。重置后该管理员原登录会话失效，学习数据不变；停用账户不会自动启用。命令需要已安装的 `.venv` 和 Python 依赖，不构建前端、不重启服务。自定义数据库必须显式指定 `WORDS_DB=/实际路径/words.sqlite3 ./sop.sh admin`，与运行服务保持一致；不会读取 `.env` 或 systemd 环境配置。仅允许可信服务器操作者运行此命令。

- 本机访问：**http://127.0.0.1:18765**。
- 其他设备：使用 `http://服务器局域网IP:18765`，不要将 `0.0.0.0` 当作访问地址。
- 默认监听所有 IPv4 网卡 `0.0.0.0:18765`；自动探测本机 IP 配置 Host 校验。
- 日志：`.run/server.log`；默认数据库：`data/words.sqlite3`。
- 启动、重启按内容哈希检查构建：前端源码、配置、依赖锁、后端 Python 或有效路径变化，或 `dist` 缺失/被手动覆盖时，重新构建；未变则跳过。依赖锁变化自动补齐依赖。systemd 模式从实际服务环境文件只读解析 `WORDS_BASE_PATH`，不会执行配置。构建失败保留旧服务与旧产物；不停止占用端口的其他程序。

**HTTP 不加密密码和会话，仅在可信局域网临时使用。不要配置公网端口转发；正式使用推荐 HTTPS。**

### 自定义配置

```sh
HOST=0.0.0.0 PORT=18765 \
WORDS_HOSTS=localhost,127.0.0.1,192.168.1.100 \
./sop.sh restart
```

| 变量 | 用途 |
|---|---|
| `HOST` / `PORT` | 脚本监听地址、端口；仅本机使用可设 `HOST=127.0.0.1` |
| `WORDS_HOSTS` | 允许访问的服务器 IP / 域名，逗号分隔；不是客户端 IP 名单 |
| `WORDS_DB` | 自定义 SQLite 路径 |
| `PYTHON` | 创建虚拟环境时使用的 Python 命令 |
| `WORDS_HTTPS` | `1` 启用 Secure Cookie；脚本还需 `TLS_CERT`、`TLS_KEY` 才开启 TLS |
| `WORDS_GOG_PRIVATE` | `1` 允许家长通过已授权的 `gog` 回退读取私有 Google 文件 |

脚本不自动加载 `.env`，也不保存自定义环境变量；重启时需再次传入。TLS、手动启动、备份恢复见[部署文档](docs/deployment.md)。

## 导入格式

```json
[
  {"word": "hello", "meaning": "你好"},
  {"word": "world", "meaning": "世界"}
]
```

- JSON 必填 `word`、`meaning`，可选 `example`、`example_translation`；导入 `id` 不作为数据库主键。
- XLSX 第一行必须有 `word`（兼容 `words`）、`meaning`，可带上述例句列；不支持 `.xls`，不猜测纠正拼错的表头。
- 重复检查限本次导入，忽略单词大小写、首尾空白；用户选择保留一条或整组排除。不同词库可有同词。
- 请求和文件不超过 2 MiB，每库最多 5000 个词。词库默认以导入时间命名，可修改。
- Google 链接先公开下载；无法公开访问时才尝试家长授权的 `gog`。格式错误不回退私有读取。服务器需预先安装并授权 `gog`，私有下载尚需真实授权联调。
- 删除会移除相应历史；重置词条保留内容、清除该词答题历史与进度。修改释义、删除、重置会结束涉及该词的活动批次，操作前有确认。

## 个人备份

每个用户可在“个人备份”导出自己的全部词库、词条、答题历史和复习进度。**文件不包含账户名、密码或登录会话**，不能当作管理员整库备份使用。

个人导入不是合并：只覆盖当前登录用户的学习数据，不修改账户名、密码，不影响其他用户；恢复的学习批次不自动继续。要求当前密码、勾选风险、输入“确认覆盖我的学习数据”和二次确认。覆盖前自动保存当前个人数据备份，文件和请求不超过 2 MiB。

## 整库备份与覆盖恢复

家长管理页提供整库导出与恢复，两者都要求重新输入当前家长密码。导出包含全部账户（含密码哈希）、词库、学习历史与复习计划，不包含登录会话、服务器密钥或 Google 授权。备份属于敏感文件，请勿公开分享。

**恢复不是合并：当前所有账户、词库和学习记录将被备份内容整体替换，所有用户退出登录。恢复后必须使用备份中的家长账户和密码。** 用户必须勾选风险确认、输入“确认覆盖整个数据库”、重新输入当前密码并再次确认。上传限 50 MiB，仅接受当前版本的有效数据库；先校验，再自动备份当前库到数据库目录的 `backups/`，最后覆盖。操作失败应检查提示，不盲目重复提交。

当前仅支持单 worker。恢复时暂停其他 API 请求，避免在途答题写入已覆盖的数据。需要回退时，从主机保管的自动备份恢复，步骤见部署文档。

```sh
.venv/bin/python -m unittest backend.tests.check_core backend.tests.check_management backend.tests.check_sources -v
npm --prefix frontend test
npm --prefix frontend run build
bash -n sop.sh
```

测试使用临时数据库。发音依赖网络与设备英语语音包，必须实机验收；复习阶段和答题趋势不代表精确记忆概率。当前不支持 Android APK、离线同步、生成式例句或云端 TTS。
